# Story 6.3: Audio build pipeline

## Status

Draft

## Story

**As a** owner,
**I want** one script that turns originals into web-ready, seamless, level-matched files,
**so that** every file loops cleanly, sits at the right loudness and stays small.

## Acceptance criteria

1. `scripts/build-audio.mjs` trims, high-passes, bakes an equal-power loop crossfade into beds, normalises loudness (beds about −28 LUFS, events about −24, thunder about −22; true peak ≤ −3 dBTP) and encodes Opus WebM plus AAC M4A into `public/audio/`.
2. Running it twice gives identical output.
3. Total output ≤ 6 MB, or the build fails.
4. Beds loop with no audible seam (checked by ear on three files).

## Tasks / subtasks

- [ ] ffmpeg wrapper with clear errors
- [ ] Loop-crossfade step for beds
- [ ] Two-pass loudness normalisation (ffmpeg `loudnorm`)
- [ ] Encode Opus (beds 56 kbps stereo, events 48 kbps mono) and AAC (80 kbps)
- [ ] Size budget check
