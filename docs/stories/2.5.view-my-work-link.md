# Story 2.5: "View my work" link in the bubble

## Status

Done

## Story

**As a** visitor who has met Tony in the field,
**I want** a way to see his work,
**so that** I can learn more about him if I'm curious.

## Acceptance criteria

1. The bubble's last line, bottom left, is a link reading "View my work" to
   https://tonyjoyk.github.io/tony-joy-portfolio/.
2. It opens in a new tab with `rel="noopener"`.
3. Clicking or tapping it doesn't end the greeting. The cursor on it keeps
   him facing the visitor.
4. It looks like the bubble's text: dark 11 px ink, semibold, a thin
   underline, and a focus ring for the keyboard. Contrast stays at least
   4.5:1.
5. It's only shown and focusable while the bubble is.
6. Tests and the build pass.

## Tasks / subtasks

- [x] `index.html`: the link as the bubble's last paragraph (AC 1, 2, 5)
- [x] `main.css`: link and focus style (AC 4)
- [x] Test: link, href, target and rel (AC 1, 2); full suite and build (AC 6)
- [x] Browser check: placement, contrast, and a click opens a new tab (AC 3–5)

## Dev notes

- Spec: greeting, Revision 4. Decision: D-2.6.
- `main.js` already ignores `pointerdown` on `.bubble` and on `a`, and
  treats the cursor on the bubble as being on him, so no JavaScript change
  is needed.
- The bubble is `visibility: hidden` when not shown, so the link can't be
  tabbed to then.
