# Story 6.4: Manifest and credits

## Status

Done (Sound credits chat)

## Story

**As a** visitor and owner,
**I want** every shipped sound traceable and credited,
**so that** the licences are honoured (D-6.2) and recordists are credited.

## Acceptance criteria

1. `public/audio/manifest.json` lists each file: role, scenes, duration, loop points in samples, and credit (title, recordist, URL, licence, edited note).
2. Files derived from BY-SA sources are labelled CC BY-SA 4.0.
3. A test fails on any licence outside the allowlist, or any missing credit field.
4. The build regenerates the README's "Sound credits" block from the manifest.

## Tasks / subtasks

- [x] Write the manifest from the build: each file now has its exact
  `samples`, and each bed's `loop` has `startSample` and `endSample` (at
  `sampleRate`, 48 kHz) beside the seconds.
  `node scripts/build-audio.mjs --manifest-only` rewrites the manifest and
  README without re-encoding the audio.
- [x] Schema and allowlist test: `checkManifest()` in `src/audio/credits.js`;
  the build fails on any problem, and `tests/audio-manifest.test.mjs` checks
  the shipped manifest against it and against `audio/sources.json`.
- [x] Generate the README block: the build rewrites the block between the
  `sound-credits` markers under "Credits → Sound credits"; a test fails if
  the README is out of date.
