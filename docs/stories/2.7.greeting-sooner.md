# Story 2.7: The greeting comes sooner

## Status

Done

## Story

**As a** visitor,
**I want** the man to respond a little sooner when I rest my cursor on him,
**so that** the greeting feels responsive without losing its calm.

## Acceptance criteria

1. The rest before he turns is 1.5 s (`greeting.dwellSeconds`, still
   tunable in the dev panel).
2. He settles in 0.65 s, and no value changes by more than 0.04 in one
   frame (the existing no-snap test).
3. The bubble starts to appear once his turn is 60% done. It shows for its
   reveal plus 4 s, counted from that moment (paused while the cursor is on
   the bubble), then he turns back.
4. Leaving him at any point still turns him back slowly and he walks on.
   A click on him while the bubble shows still dismisses it.
5. Tests and the build pass.

## Tasks

- [x] `config.js`: `dwellSeconds` 1.5
- [x] `greeting.js`: `SETTLE_SECONDS` 0.65; `BUBBLE_AT_TURN` 0.6; `facing`
  includes the late turn; `faceT` counts from the bubble's appearance
- [x] `Scene.bubbleShown` uses `greeting.facing`
- [x] Tests updated (dwell, bubble window, hold) and measured
