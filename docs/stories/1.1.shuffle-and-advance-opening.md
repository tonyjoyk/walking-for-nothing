# Story 1.1: Random opening scene, next scene on every reload

## Status

Done

## Story

**As a** visitor,
**I want** the site to open on a random scene, and to move on to the next
scene each time I reload,
**so that** every visit feels fresh and reloading lets me step through the
day.

## Acceptance criteria

1. Given no remembered scene in this tab, when the page loads, then it opens
   on one of the six scenes chosen at random. Each scene is reachable.
2. Given the tab last showed scene X, when the page is reloaded, then it opens
   on the scene after X in the order Dawn → Daylight → Windy → Rain → Sunset →
   Night → Dawn.
3. The remembered scene follows what was on screen. If a crossing moved the
   scene from Sunset to Night, a reload opens on Dawn.
4. The opening scene appears on the first frame, with no transition in from
   another scene.
5. `?weather=<scene>` and the dev panel's forced opening scene still take
   precedence, and the forced scene is remembered: opening the plain address
   afterwards advances from it. Reloading the `?weather=` address itself keeps
   forcing that scene, as the address asks.
6. Live weather is off:
   - the default opening mode is shuffle;
   - the page doesn't request `weather.json` in shuffle mode;
   - the published `weather.json` has `enabled: false`;
   - weather mode can be chosen in the dev panel.
7. If `sessionStorage` is unavailable or throws, every load is random and no
   error appears.
8. Crossings still advance the scene. Juhu, the birds and the greeting are
   unaffected.
9. Settings save and load: `opening.mode` is validated, and an old
   `liveWeather` key is ignored.

## Dev notes

- Planning pack: `docs/bmad/opening-scene-shuffle.md`. Live weather spec:
  `docs/spec-live-weather.md`.
- Storage key: `wfn.lastScene`, in `sessionStorage`. It survives a reload and
  is cleared when the tab closes, which is exactly the load/reload split the
  request needs.
- Overcast is remembered as itself. `next('overcast')` is Sunset, because
  overcast sits at Rain's place in the cycle.

### Testing

- `npm test` (Node `node:test`): pure functions, Scene hook, config.
- Browser: clear the session, load, reload ×6, and check the sequence. Check
  that no `weather.json` request is made in shuffle mode.
- Production: `npm run build`, deploy, and check the live site loads and
  reloads in order.
